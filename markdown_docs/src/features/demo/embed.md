## FunctionDef build_demo_embed(index)
**build_demo_embed**: The function of build_demo_embed is to construct and return a Discord embed object with a dynamic description based on an index and a default color.
**parameters**: 
· index: An integer value that determines the textual content of the embed's description field.
**Code Description**: This function initializes and returns a discord.Embed instance configured with two primary attributes. The description is dynamically formatted as a string combining the literal text "embed " with the provided index parameter. The color attribute is assigned from an external constant named DEFAULT_EMBED_COLOR, which must be defined in the same module or imported beforehand. Within the project architecture, this function serves as a factory method for generating standardized embed objects. It is invoked by the demo command handler in src/features/demo/command.py, where it is called iteratively within a list comprehension to generate a sequence of embeds ranging from 1 to MAX_DEMONSTRATION_EMBED. The resulting list is subsequently passed to the Discord interaction response mechanism to display multiple formatted messages simultaneously. The function operates synchronously and does not perform input validation or error handling, assuming the caller provides a valid integer and that DEFAULT_EMBED_COLOR is properly initialized.
**Note**: Ensure that DEFAULT_EMBED_COLOR is defined as a valid hexadecimal color integer before invoking this function. The index parameter should be an integer to prevent formatting errors in the description string. This function does not validate whether the generated embeds exceed Discord's API limits for message attachments or embed counts.
**Output Example**: <discord.Embed object at 0x7f8a9b2c1d40> with description='embed 5' and color=0x3B82F6
